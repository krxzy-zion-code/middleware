# Middleware

Ordered middleware pipeline for Roblox Luau applications.

Wally package: `krxzy-zion-code/middleware`

## Install

Add this to your project's `wally.toml` under `[dependencies]`:

```toml
Middleware = "krxzy-zion-code/middleware@0.1.1"
```

Then run:

```powershell
wally install
```

## Publish

Run `wally publish` from this directory.
